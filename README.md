Dashboard pribadi sederhana buat ngatur kegiatan sehari-hari. Dibuat pakai HTML, CSS, dan JavaScript 

Fitur utama:
- Jam dan tanggal real-time
- Berdasarkan waktu (Pagi, Siang, Sore, Malam)
- Timer fokus dengan tombol Mulai, Berhenti, dan Reset
- Daftar tugas, bisa tambah, edit, tandai selesai, dan hapus. Datanya tersimpan

Fitur tambahan:
- Mode gelap dan terang
- Bisa ubah durasi timer
- Tidak bisa tambah tugas yang sama dua kali
- Bisa urutkan tugas
